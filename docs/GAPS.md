# Gaps / Open Questions

This project intentionally minimizes blocking decisions in early milestones by using safe defaults
and configuration-driven behavior.

At this time, no blocking gaps have been identified that require stopping autorun immediately.
Future advanced capabilities (P2) may require decisions (e.g., preferred CFD data formats, root selection
policy under multi-root non-monotonic kinetics). If/when those become blockers, they must be recorded here
and added as `type="decision"` tasks in `tasks/tasks.json`.
