# 表面運動論と縮約に基づく推定・役割選択

2026-09-04。状態：標準次数の定常CVD縮約、合成パラメータ推定、物理的境界候補、既存の条件外選択・役割判定への接続まで実装済み。実装は `src/deposim_opt/cvd_surface_kinetics.py`、実行経路は `cvd_multicond_analysis.py` と `scripts/analyze_cvd_multicond_case.py`。設計前の数値根拠は `results/surface_kinetic_review_20260903/`、実装後の評価は `results/cvd_surface_qss_20260904/` に保存した。

目的は Fluent の raw species を説明可能な反応役割へ割り当て、実測の成膜速度・膜厚分布を条件をまたいで予測すること。CVD と ALD の時間構造を保ち、データに特化した係数調整や species の固定で精度を作らない。

## 1. 悪化の直接原因を更新する

先行評価では、共通係数と条件間・面内分離を同時に選ぶと、全体RMSEが 0.0582951 → 0.0687815 nm/s、MSEが39.2%悪化した。しかし、追加の切り分けは「分離モデル自体が悪い」という説明を支持しない。

各外側分割の学習条件だけを使い、(a) 共通係数モデルで役割を選ぶ、(b) その役割を固定して分離モデルで正則化を選択・再推定する、という二段階の比較を行った。

| 外した条件 | 従来の役割選択・共通係数 | 従来の役割を固定・応答分離 | 役割も分離モデルで選び直す |
| --- | ---: | ---: | ---: |
| 4 | 18.109% | **0.794%** | 19.527% |
| 5 | 63.447% | **1.208%** | 74.934% |

値は相対RMSE。条件4・5の従来候補は `AI:adn_2|n2`。役割を固定した分離モデルは学習内CVで λ=1e-6 を選ぶ。一方、分離モデルで役割も選ぶと `I_response:idn_2`、λ=0 が選ばれる。

条件5の内側CV RMSEは、役割を固定した分離モデルが0.0145639、新たなI応答が0.00697812 nm/s。学習内指標では後者が良いため、現在の順位処理はその規則どおりに選んでいる。外した条件では評価が逆転する。

二段階の比較は全5条件で相対RMSE 0.576～1.208%、全点RMSE 0.00130793 nm/sになった。役割選択・係数推定に外した条件の実測値は入れていない。ただし、この手順自体を今回の失敗を見て追加検討しており、開発に再使用した5条件での結果である。新しい独立性能評価ではない。これだけで二段階方式を製品の最終設計へ昇格させない。

この結果から言えるのは、現在の入力でも低誤差の候補は存在し、**候補の物理的意味と選択手順が重要なボトルネック**になっていること。データ不足だけを原因とする説明も、役割を外側結果に合わせて固定する対処も適切ではない。

## 2. 推定構造のどこが弱いか

### 2.1 条件平均と面内偏差の分離で、局所情報との結合を失った

分離モデルの対数速度は次式である。

```text
z_ji = alpha + mean_j(x) * beta_between + (x_ji - mean_j(x)) * beta_within
```

全マップの観測点が揃い、条件ごとの点重みが一様な場合、正則化なしの損失は厳密に次の二つへ分解する。

```text
L = mean_j[(mean_j(z) - alpha - mean_j(x)*beta_between)^2]
  + mean_j mean_i[((z_ji-mean_j(z)) - (x_ji-mean_j(x))*beta_within)^2]
```

実測値の平均はこの式の説明・解析に使ったもので、予測時の補正ではない。

外側学習は196点でも条件間係数を支える平均値は4個、内側の再推定では3個である。面内の点数が増えても、この部分の独立な条件数は増えない。λ=0では二つの係数群を結ぶ罰則も消える。条件4・5の選択結果では、条件間のI係数が43.02・81.17、面内の総濃度係数が22.24・21.20になった。

同一の表面反応でも、大きな条件変更に対する割線の傾きと、ある条件内の局所的な接線の傾きは異なり得る。次の設計では、その違いを**共通の非線形反応式から生じさせる**。二つの傾きを独立に自由推定することを表面運動論の代わりにしない。

現行式は `beta_between - beta_within` が非ゼロなら、他地点の入力が変わってマップ平均が変わるだけでも、局所入力が同じ地点の予測が変わる。この依存を説明する表面・輸送収支はない。CFDが与える局所状態と実際の境界条件から反応速度を決める方が、格子や評価範囲への依存を整理できる。

損失の分解は再計算で確認した。[数値根拠](../results/surface_kinetic_review_20260903/between_within_geometry.csv)

### 2.2 組成に対する係数の符号が、そのまま表面での役割を示すわけではない

例えば共通係数のI応答は、定数を省略すると次式になる。

```text
r = C_total^p * (C_I / C_total)^(-b)
  = C_total^(p+b) * C_I^(-b)
```

総濃度を固定して組成を置換する場合は抑制方向でも、他の絶対濃度を固定して C_I を増やす場合の感度は

```text
d log(r) / d log(C_I) = (p+b) * fraction_I - b
```

となり、正にもなる。条件4を外した従来のI=n2応答では、この値が観測点上で **+0.779～+0.784** だった。これはn2の化学的性質を推定した結果ではなく、今の「I」が固定総濃度での組成応答という定義であることを示している。

表面サイトを占有するI、吸着して成膜中間体を作るA、変換を促すBを推定したいなら、その役割を表面収支の中で定義する必要がある。総濃度の自由なべき項は比較用の経験基準として残せるが、反応役割の根拠にはならない。輸送や密度の影響は、対応する入力と輸送則がある経路で扱う。

[絶対濃度への感度の再計算](../results/surface_kinetic_review_20260903/absolute_concentration_sensitivities.csv)

## 3. 最優先：既存AIB表面収支から小さなCVD速度式を導出する

新しい詳細化学機構を追加するより、まず [既存AIB核](../src/deposim_sim/models/aib_ode.py) の標準次数 `(m_ads, p_A, p_star)=(1,1,0)`、`nu_A=1` を基点にする。以下はこの仮定での導出であり、全反応への普遍的な速度式ではない。

- Aは空きサイトへ吸着し、被覆状態 `theta_A` を作る。
- Iは同じサイトを占有する。十分速い可逆吸着なら `theta_I = K_I C_I,s theta_free`。
- A状態は脱離、または成膜反応で消費される。
- Bありでは気相／表面到達Bが変換に関与し、Bなしでは単独変換経路を比較する。

```text
theta_free + theta_A + theta_I = 1
a = k_ads * C_A,s
d = k_des
q = k_convert_A                    [A / AI]
q = k_convert_AB * C_B,s           [AB / AIB]
i = K_I * C_I,s

d theta_A / dt = a*theta_free - (d+q)*theta_A
v = H*q*theta_A
```

`v` は膜厚増加速度。`H` は観測量への換算係数で、既存CVD核では `alpha_h * Gamma_s` に対応する。定常表面を仮定して被覆率を消去すると、

```text
theta_A = a / [a + (d+q)*(1+i)]
v = H*a*q / [a + (d+q)*(1+i)]
```

を得る。単に吸着平衡のLangmuir式を入れるのではなく、分母に成膜によるA消費 `q` を残す点が重要である。吸着平衡と準定常は同じ近似ではない。

この式では、飽和、競合占有、A供給とB変換の律速の切替が同じ少数パラメータから生じる。条件間と面内に共通の式を使っても、局所感度は被覆状態に応じて変わる。

この標準次数では、他の表面濃度を固定したA・Bの対数感度は0～1、Iは−1～0に収まる。これは反応式から生じる性質であり、経験係数を後からその範囲へクリップする規則ではない。空きサイトを必要とする反応や協同吸着など別の次数・機構には、その式から導く性質を使う。

0濃度・高濃度での極限、被覆率の0～1、サイト収支、A/B供給が途絶えたときの定常成膜停止を式として検証できる。既存次数から導いた式について、1000組の正の係数でサイト収支と定常残差を数値確認した。実装後は合成データでサイト収支、AIB応答回復、濃度単位不変性、定常AB交換対称性、学習基準値の固定も自動テストしている。

表面被覆率と輸送を結び付けた小さなモデルを膜厚分布へ合わせる方向は、例えば [Ylilammi et al. (2018)](https://doi.org/10.1063/1.5028178) のALD研究とも整合する。ただし同論文の個別プロセスの定数や性能を本データへ転用するものではない。

## 4. 縮約を「項の削除」から「物理的な極限と合成パラメータ」へ変える

### 4.1 最初から観測で推定できる組合せを使う

A/AIの定常速度式では、

```text
V_max = H*k_convert_A
C_half = (k_des + k_convert_A) / k_ads
v = V_max*C_A,s / [C_A,s + C_half*(1 + K_I*C_I,s)]
```

と書ける。速度マップだけから `H, k_ads, k_des, k_convert_A` を別々に推定するのではなく、まず `V_max, C_half`、必要な場合に `K_I` を推定する。

AB/AIBでも、基準濃度で無次元化して `a_ref=k_ads*C_A,ref` とすると、

```text
u_A = C_A,s / C_A,ref
u_B = C_B,s / C_B,ref
u_I = C_I,s / C_I,ref
R = H*a_ref
delta = k_des/a_ref
b = k_convert_AB*C_B,ref/a_ref
kappa = K_I*C_I,ref

v = R*u_A*b*u_B / [u_A + (delta+b*u_B)*(1+kappa*u_I)]
```

となる。原始定数の数より少ない、出力を決める3～4個の合成パラメータで扱える。基準濃度は各学習集合だけで固定し、単位換算で予測や比較が変わらないようにする。

全ての動的速度を同じ倍率で変え、Hを逆倍率にすれば、この定常式は同じ速度を返す。したがって、定常速度だけから表面の緩和時間まで同定できるわけではない。数値確認でもこの非一意性を再現した。

### 4.2 効果が見えない境界にも意味がある

| 親式の極限 | 縮約される応答 | 役割に関して言えること |
| --- | --- | --- |
| `K_I → 0` | I依存のない反応式 | 観測上I項を必要としない候補と比較できる |
| `a << (d+q)*(1+i)` | `v ≈ H*a*q/[(d+q)*(1+i)]` | Aへの低被覆応答。複数定数が積・比として現れる |
| `a >> (d+q)*(1+i)` | `v ≈ H*q` | A濃度への感度は小さくても、A供給の機構的必要性は消えない |
| `q >> d, a/(1+i)` | `v ≈ H*a/(1+i)` | B依存が見えない供給律速。Bが反応に不要とは言えない |
| `d → 0` | `v = H*a*q/[a+q*(1+i)]` | 脱離なしの逐次反応。必要な合成定数を残す |
| I吸脱着が十分速い | `theta_I = K_I*C_I,s*theta_free` | 動的I状態を代数式へ落とす。Iの占有効果は残る |

各境界を独立した小さな候補として同じ学習条件で再推定する。異なるパラメータを同時に0・無限大へ動かして有限の合成定数を残す場合もあり、一個の係数を0へ設定するだけでは正しく縮約できない。

この方針は、パラメータの境界・極限から小さな説明可能モデルを作る [Transtrum & Qiu (2014)](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.113.098701) の考え方に沿う。ここでは自動MBAMや大規模なモデル縮約基盤を導入せず、上記の少数の解析的極限を実装すればよい。

### 4.3 縮約で失われる役割の区別も出力する

Iなしの最小定常AB式は `v=H*a*q/(a+d+q)` であり、aとqの交換で同じになる。吸着Aと変換Bを区別する動的な親モデルを持っていても、この定常観測だけでは対応パラメータの交換を含めてA/Bを区別できない。物理モデルを選んだだけで方向まで特定したと報告してはいけない。

したがって、縮約には次の二つを持たせる。

1. どの観測応答・合成パラメータが残るか。
2. どの親役割・素過程が区別できなくなったか。

現在の `role_evidence` の効果必要性を、そのまま反応物の機構的な有無へ変換しない。高速B極限なら「B感度は未特定」、定常AB対称性なら「AB対まで」を既存のrole summaryに記録する。候補の名称や数から支持を増やさない。

## 5. 推定・選択でコード側が行うこと

### 5.1 観測に現れない自由度を探索から除く

`v = R*f(C; eta)` と書ける場合、重み付き二乗誤差に対するRは、etaを固定すると解析的に求まる。

```text
R_hat = max(0, sum(w*f*y) / sum(w*f*f))
```

これにより非線形探索は形状パラメータetaだけになる。対数誤差なら対応する対数振幅の解を使う。振幅が輸送や状態へフィードバックする場合にはこの消去を無条件には適用せず、分離可能な部分を先に整理する。

線形な係数を消去して非線形変数だけを探索する手法は [Golub & Pereyra (1973)](https://epubs.siam.org/doi/abs/10.1137/0710036?journalCode=sjnaam) に基づく。今回の目的では、初期値への依存と不要な探索次元を減らすために使う。

### 5.2 誤差の単位と推定目的を揃える

現在の経験モデルは対数誤差で推定し、元の速度単位のMSEで選択する。これは明示済みの設計であり実装バグではないが、全体の物理量誤差を下げる目的には、観測量での条件重み付き誤差による推定を比較する価値がある。

まず同じ損失のまま反応式の変更を比較し、次に損失の変更を別の比較で評価する。平均誤差と面内誤差の分解は維持する。同じ重みで二つのMSEを足すだけなら元のMSEと同一であり、名前を分けても改善は起きない。測定誤差が未知のとき、実測の小さな面内標準偏差を測定精度と見なして重みを決めない。

### 5.3 識別性を縮約へ接続する

既存のSVD・感度解析を入口にし、最終候補の合成パラメータについて、値を固定して他を再推定する少数の損失プロファイルを調べる。損失がほぼ変わらず物理境界へ進む方向があれば、対応する解析的縮約候補と比較する。

手法の参考は [Raue et al. (2009)](https://doi.org/10.1093/bioinformatics/btp358)。測定誤差モデルがない場合は損失プロファイルとして使い、95%信頼区間や支持確率を自動的に付けない。新しい警告を増やすことより、識別できない原始定数を合成定数へ置き換えることを優先する。

役割・縮約・正則化の選択は引き続き学習内で完結させる。外した条件を見て係数上限、種別、役割を修正しない。今回の二段階経験モデルは有用な比較対象として保持するが、それを表面運動論の同定成功とは扱わない。

## 6. 輸送とALDで省略してはいけないもの

### 6.1 濃度を表面へ渡す経路を揃える

反応式の入力 `C_s` は表面での濃度である。Fluentから既に表面濃度が与えられるなら、それにさらに同じ濃度降下を掛けない。基準面濃度なら、情報がある場合に限り既存の物質移動処理を使う。

```text
J_A = k_m,A*(C_ref,A - C_s,A)
    = Gamma_s*(d theta_A/dt + nu_A*R_event)
```

定常・νA=νB=1なら、A/Bの輸送流束は成膜イベントの消費と一致する。この関係と反応速度式を同時に解く。最小の単調な反応式では、供給流束による上限で区間を作り、1次元の求根で結合できる。成膜と脱離を別々の正の吸収として二重に差し引かない。

`k_m`、表面サイト密度、膜への換算係数が別々に識別できなければ、必要な輸送・反応比や速度換算の合成値を推定する。単一の膜速度マップから全ての原始定数を推定しようとしない。今回の入力だけで濃度の採取面や輸送係数を確定できない場合、まず見かけの速度式として扱い、真の吸着定数・物質移動係数と呼ばない。

### 6.2 定常入力と定常表面は区別する

現行 `pipeline._simulate_steady` も、定常Fluent入力の下で表面状態を時間積分している。`time_mode=steady` という名前だけで表面準定常へ自動置換しない。

表面緩和が工程時間や入力変化より十分速い範囲でQSSを使う。立上りを含む平均成膜速度なら時間積分を残す。時間情報のない定常マップから緩和時間を一意に求めることはできないため、QSSは明示したモデル仮定として検証する。

### 6.3 ALDでは必要な記憶状態を残す

ALDでAとBの供給が時間的に重ならない場合、平均濃度や瞬時の `C_A*C_B` に縮約すると、Aの蓄積を経由した成膜を表せなくなる。A状態と、必要ならI状態を残し、速いI吸脱着だけを平衡化する等の縮約を行う。CVD用の定常式をALDへ一律適用しない。

固定された表面入力で一次遷移を使う最小モデルなら、空きサイト・A・Iの3状態に対する非負の遷移率を用い、サイト総和を保つ小さな陰解法や区間遷移で更新できる。膜増分は同じ離散化での成膜遷移量から計算する。

現在のALD核は陽的更新後に被覆率をクリップ・投影しているため、状態の有界性と反応消費の整合は同じものではない。ALDを改良する際は、この更新を収支の合う方式へ置き換える価値がある。これは今回の経験CVD評価の悪化原因ではない。

| モデル固有の候補・縮約定義 | 許される物理的極限、原始定数から合成定数への関係、観測上の対称性 |
| `fit_roles.py` | 既存の学習内選択・条件外検証を使い、各縮約を独立に再推定 |
| `class_compare.py` | 予測差から役割支持へ接続し、飽和・供給律速・交換対称性で失われる区別を報告 |
| `objective.py` / 観測アダプタ | 速度・膜厚、瞬時・工程平均、単位と誤差の対応 |

最初に実装する範囲は、標準次数の定常CVD縮約、2～4個の合成パラメータ、少数の極限候補、既存の候補比較への接続までとする。輸送の自由度追加やALDの状態拡張は、それぞれ必要な入力と検証がある段階で行う。新しいデータ契約群や縮約フレームワークを作る必要はない。

比較対象はまず三つに絞る：従来の共通べき応答、今回の二段階経験手順、表面収支から導いた縮約モデル。同じ外側分割・同じ観測量で全体誤差、条件別誤差、面内形状を比較する。新しい反応式の精度向上を前提にしない。

実装の検証では、既知の表面モデルから生成した条件での回復、低被覆・飽和・供給律速の極限、表面収支、AB交換が見えなくなる条件、入力単位・格子変更への整合を確認する。QSSと親ODEの差も、対象とする時間範囲・係数範囲で比較する。

## 8. 実装後のdata評価

標準コマンドは `surface_qss` を使い、条件1・2・4・5だけで役割と縮約を選び、条件3を無再適合で評価する。さらに全5条件を一つずつ外した外側評価を行う。

```bash
wsl.exe bash scripts/commands.sh analyze_cvd_multicond \
  --response-model surface_qss \
  --output results/cvd_surface_qss_20260904
```

外側5分割の全点RMSEは0.00353856 nm/s、条件別相対RMSEの単純平均は1.4377%だった。従来の標準経験モデルの同じ外側評価は0.0582951 nm/s、17.2263%であり、QSS縮約は条件平均の転送誤差を大きく下げた。主分割（1・2・4・5で学習、3を評価）は相対RMSE 0.6699%だった。

面内形状は別である。主分割の centered R² は -0.0194、外側5分割のうち正だったのは条件4だけだった。選択役割も `AB(adn_2,idn_2)` を中心に、I項の有無とA/B方向が分割で変わる。I項を含む主候補の `kappa` は小さく、IなしAB候補の条件CV RMSEとの差も小さい。このため出力は予測水準の改善と、役割・面内形状の未解決を分け、採用判断を `review` とする。

この評価データは設計検討にも使っているため、新規の独立性能保証ではない。改善の意味は「表面収支から導いた少数自由度の候補が、経験べき則よりこの条件外評価に適合した」であり、真の機構や原始速度定数を確定したという意味ではない。

## 9. コード側でできることと限界

コード側でできるのは、表面収支を保った候補に変えること、識別不能なパラメータを減らすこと、縮約の意味を保つこと、観測量に合う推定と同じ検証条件での選択を行うこと。今回の切り分けは、データ追加前にも推定・選択設計を改善する余地があることを示した。

一方、真の反応機構・原始速度定数・独立評価での精度は、式を物理的に整えただけでは確定しない。濃度の採取位置、温度・時間条件、測定の反復と精度、必要な独立組成変化はデータ・工程側の情報である。特に定常式が持つAB対称性は同じ種類の定常点を増やしても解消せず、異なる感度を持つ観測・過渡条件が必要になる。

コード改良の到達目標は、**同じ表面収支で平均水準と面内形状を説明し、観測で区別できる役割と合成パラメータだけを報告すること**である。

再現：`wsl.exe bash results/surface_kinetic_review_20260903/run_review.sh`。数値結果とコードハッシュは [review_evidence.json](../results/surface_kinetic_review_20260903/review_evidence.json) に保存した。
