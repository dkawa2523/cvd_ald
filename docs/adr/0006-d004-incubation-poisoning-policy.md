# ADR 0006: D-004 核生成遅延・被毒状態モデルの昇格方針

- 日付: 2026-02-19
- 状態: 採択
- 判断課題: `D-004`

## 背景

`model_explain.md` は、核生成遅延と被毒の明示的状態（MS-11/MS-12）を提案している。現在の実行系には基本的な状態閉包の骨格があるが、状態変数、駆動化学種、結合規則、識別条件という機構仕様は要件水準のインターフェースとして標準化されていない。

AGENTSおよびPOLICY_LOCKに従い、モデル備考から実装範囲への昇格には、正式な要件仕様と試験判定条件設計が必要である。

## 判断

`D-004` における核生成遅延・被毒モデルの昇格を次の状態とする。

- `DEFERRED`

この判断では要件水準へ昇格させない。

## 理由

1. 一部の骨格は存在するが、機構上の意味を安定した判定条件にできるほど固定していない。
2. 現時点で直接昇格すると、縮約状態閉包と機構状態の境界が曖昧になる。
3. 明示的な実験・パラメータ方針なしでは識別性リスクが高い。

## 影響

1. この判断では新しい状態APIを追加しない。
2. `docs/GAPS.md` に、再検討条件とともに保留項目として残す。
3. 将来採用する場合は、状態仕様と決定論的受入れ試験を先に定義する。

## 再検討条件

次のいずれかを満たしたときに再検討する。

1. 対象プロセスの残差を説明するため、明示的な核生成遅延または被毒動力学が必要になる。
2. これらの状態を識別可能な較正データが得られる。
3. 判断またはADRがYAML スキーマ、検証部規則、回帰試験を定義する。
